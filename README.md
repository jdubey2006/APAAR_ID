# VIDYASetu | AICTE APAAR Student Data & Verification Platform

**Smart India Hackathon 2026 • Problem Statement PS-26263**  
*“Development of an APAAR ID-Based Student Data Management and Verification Platform for AICTE-Approved Institutions”*

---

## 🌟 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run the platform locally
npm run dev
```

Open your browser at: **`http://localhost:5173/`**

---

## 🚀 Key Prototype Highlights for Hackathon Evaluators

1. **▶ Start Judge Demo**: Click the blue "Start Judge Demo" button in the top navbar for an interactive 12-step guided presenter walkthrough.
2. **Simulation Controls**: Top-bar controls to trigger real-time simulated events (e.g., `+100 Student Ingestion`, `Trigger 98.2% Duplicate`, `Trigger Excess Intake Breach`).
3. **Role-Based Access (Demo Switcher)**: Switch between **AICTE Super Admin**, **Verification Officer**, **Institution Admin**, **Student Scholar**, and **External Verifier** in one click.
4. **Data Submission Center**: 6-step ingestion wizard with automatic column header detection and live animated validation of 48,291 records.
5. **Duplicate Intelligence Center**: Side-by-side identity comparison (96.8% match) and interactive **Cross-Institution Network Graph**.
6. **Privacy-by-Design**: Masked APAAR IDs by default (`XXXX XXXX 4821`) with audited cryptographic reveal authentication under the **DPDP Act 2023**.
7. **Verifiable Digital Credential**: Government-grade credential cards with cryptographic seal and functional QR code verification.
8. **VIDYA AI Assistant**: Floating AI assistant answering natural language questions on institutional compliance, intake anomalies, and APAAR coverage.
9. **Dark / Light Mode**: Government deep navy / charcoal dark mode + accessible light mode.
